1. PRODUCT VISION

Build a real-time AI voice conversion platform inspired by the user experience of products such as Altered AI RealTime Pro, but DO NOT use Altered AI’s proprietary API, backend, infrastructure, models, or restricted services as the foundation of this competing product.

The platform should allow a user to:

1. Select a voice model.
2. Speak into a microphone.
3. Capture the microphone audio.
4. Process the audio through an AI voice-conversion pipeline.
5. Return the converted audio with minimal latency.
6. Route the processed audio to supported applications.
7. Record or stream converted audio.
8. Manage voices and models.
9. Monitor session quality.
10. Eventually use the same platform across Windows, Android, and iOS.

The platform must support a hybrid architecture:

LOCAL + CLOUD GPU

Where possible:

* run locally
* use free compute
* use remote free GPU
* use paid GPU only when necessary
* scale paid infrastructure to zero when unused
* automatically recover from failed workers
* avoid unnecessary infrastructure costs

The ultimate business model should allow:

$0 infrastructure at the beginning where realistically possible.

Then:

USER DEMAND → GPU CAPACITY → BILLING → REVENUE → MORE CAPACITY
